# 優先支援整套產品的雲端與地端部署可攜性

本專案的目標是可重用的企業系統骨架，日後承載不同業務模組。使用者已確認第一優先驗收情境是：同一套產品可以整套部署在雲端或客戶地端。

因此，後續架構與套件評估以整套產品的部署可攜性為出發點；雲地拆分協作、地端斷線操作與恢復連線後同步，若成為需求，再另行評估其資料與通訊邊界。

第一版地端交付接受「應用程式、資料庫、獨立背景工作服務」的部署組合。背景工作服務的職責與訊息交付方式尚待確認。

Wolverine 是否採用、資料庫選型，以及是否需要額外的訊息中介服務，尚未決定。
